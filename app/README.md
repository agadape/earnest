# Tanda Jadi web app

The interface, the TypeScript client (`src/lib/tanda-jadi/`) and the dev scripts (`scripts/`).
How to run everything is in the README one level up.

Environment variables are described in `.env.example`. With `NEXT_PUBLIC_DEMO_WALLET=1` the app
offers a play-money wallet that lives in the browser and a "Get demo dollars" button, so it can
be tried without installing a wallet. Leave that out wherever the token is worth something.
